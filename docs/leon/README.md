# Léon — BATORYA Essentiel V6

## Objet

Cet espace est le point de départ documentaire du nouveau développement de Léon pour BATORYA Essentiel V6.

La conception repart des besoins et des règles validées de BATORYA Essentiel V6. Les documents historiques de la branche V5 sont des sources d'expérience, pas des spécifications automatiquement applicables à V6.

## Principes de travail

- Définir le besoin et le périmètre avant de choisir une solution technique.
- Distinguer les règles déterministes, l'interprétation éventuelle par un modèle local et les réponses ou actions autorisées.
- Privilégier la fiabilité, la traçabilité et le fonctionnement local.
- Construire les intentions et les cas de test à partir du métier V6 validé, sans reprendre arbitrairement les anciens volumes.
- Comparer les modèles à partir d'un protocole reproductible ; aucun modèle n'est présélectionné comme gagnant.
- Valider chaque étape avant de passer à la suivante.
