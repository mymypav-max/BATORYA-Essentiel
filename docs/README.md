# Documentation — BATORYA Essentiel

Ce dossier contient la documentation de conception, les décisions fonctionnelles et techniques, les audits, les spécifications et les documents de référence du produit BATORYA Essentiel.

## Organisation

Les documents seront ajoutés au fur et à mesure de l'avancement du projet.

- `audit/` — audits et analyses de l'existant
- `conception/` — conception fonctionnelle et technique
- `migration/` — migration des données et compatibilité V5/V2
- `decisions/` — décisions d'architecture et décisions métier
- `specifications/` — spécifications détaillées

Le contenu de `docs/` ne constitue pas du code applicatif. Les documents doivent rester cohérents avec le CDC BATORYA Essentiel V6 et les décisions validées au cours du projet.
