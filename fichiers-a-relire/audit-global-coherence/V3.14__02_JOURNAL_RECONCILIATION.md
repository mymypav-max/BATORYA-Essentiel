## Statuts utilisés

| Statut | Sens |
|---|---|
| **VALIDÉ + SQL** | décision de la consigne du 2026-10-15 **et** comportement vérifié dans la migration |
| **VALIDÉ (service)** | décision de la consigne ; aucune garde SQL livrée (service absent du dépôt : non vérifiable) |
| **CONSTAT SQL** | comportement vérifié dans une migration, sans décision explicite dans la consigne ; le statut officiel de la règle n'est pas établi |
| **PROPOSITION** | rédaction proposée, à valider |
| **OUVERT (AR-nn)** | question non tranchée, renvoyée aux arbitrages restants |

| **À IMPLÉMENTER** | règle validée dont la garde SQL n'existe pas encore (migration future) |
| **ÉCART SQL 006** | comportement du SQL livré contraire à une règle validée : correction requise, non faite ici |
