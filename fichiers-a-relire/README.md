# Fichiers à relire

Ce dossier est réservé aux fichiers générés par les assistants de développement et déposés temporairement pour vérification avant intégration dans le dépôt.

## Règles

- Déposer ici les fichiers complets à relire.
- Ne pas considérer ces fichiers comme intégrés à l'application tant qu'ils n'ont pas été vérifiés et déplacés vers leur emplacement définitif.
- Après validation et intégration, supprimer les copies de ce dossier.
